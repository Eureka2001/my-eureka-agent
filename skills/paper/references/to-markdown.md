# 论文转 Markdown

将论文整理为后续综述写作、方法比较和文献检索可直接读取的资料。保留原文语言和完整论述；不以摘要、翻译或阅读笔记替代原文。库位置、文件夹命名、索引结构见 SKILL.md 共享约定。

## 输入与状态管理

- 接受指定的论文文件（PDF、TeX 源码、HTML 等格式均可）、论文清单或目录。未指定输入位置时，先向用户确认要处理哪些论文；没有论文时，报告缺少的输入，不以其他论文替代。
- 库索引是状态的事实源：开工先读库根目录 `index.md`（没有就按共享约定新建），从"解析状态"列读续做点；不在索引里的散篇论文，转换前先追加索引行（URL 列填 `—`）。
- 已有输出且源文件未变则跳过或续做；部分完成时从已记录位置继续，保留人工修订，不静默覆盖。
- 保留源 PDF；只处理授权范围内的论文和输出。

## 效率约束（防过度打磨）

- 源 PDF 均有可用文本层，以 pymupdf 文本提取为主，不做 OCR，不做全文渲染比对。仅个别扫描版 PDF 例外，此时才用 OCR 加页面检查。
- 输入没有 PDF 时（仅 TeX 源码或 HTML）：正文直接从该来源转录，篇级 index 注明无页码锚点，页码类标注相应省略。
- 提取一律用本 skill 的固定脚本 `scripts/extract_pdf.py`（用法见脚本 docstring：`extract` 正文提取、`outline` 章节候选、`refs` 参考文献切分），不临场编写提取代码。归栏拼装、页眉页脚去除、断词修复、页码标记都是脚本已实现的确定性逻辑。
- 脚本输出即初稿：模型的工作是在脚本输出上做章节映射、公式/表格校对和六文件拼装，不是从 PDF 文本层逐字重写正文。
- 渲染页面只用于确认个别读不清的位置，不是常规步骤。整篇逐页渲染目检、词级/句级覆盖率校验、多分辨率放大取证均不需要。
- 核对以抽查为主：检查首页、各章节交界处，以及全部编号公式与表格——直接对照已提取的文本即可，无需截图。
- 状态只分两档：**已完成**（抽查无问题）、**部分完成**（仍有待核对标注）。不使用「已核对完成」一类暗示全量校验的说法。

## 每篇论文的输出

在论文文件夹内创建以下文件。保留原论文的章节名称、编号和层级；文件分类不代替原始章节结构。

| 文件或目录 | 内容 |
| --- | --- |
| `intro-related-work.md` | 完整 Introduction 和 Related Work；相关工作在引言内部时保留其原位置。 |
| `method.md` | 完整方法，以及服务于方法的问题定义、Background、Preliminaries、模型、算法和训练目标。 |
| `experiments.md` | 完整实验，包括数据集、设置、指标、主结果、消融、定量与定性分析。 |
| `abstract-conclusion.md` | 完整 Abstract 和 Conclusion；Discussion、Limitations 等独立章节保留原名称后归入此文件。 |
| `references.md` | 完整参考文献，保留原编号或作者年份标识，以及原文提供的 DOI、URL 等信息。 |
| `index.md` | 论文元信息、源文件链接、文件导航、章节页码映射、处理状态和待核对事项。 |
| `appendices/` | 按原始附录结构或主题拆分的 Markdown；内容很少时可合为一个文件。仅有附录时创建。 |
| `assets/` | 默认不创建、不提取图片；仅当用户明确要求提取图片时创建。 |

将其余实质内容按用途归入上述文件，并在 `index.md` 记录归属。原文确实没有某类内容时，仍保留四个主体 MD，并注明"原文无独立对应章节"或其实际归属，不补造内容。正文中的嵌入式相关工作只在原位置保留一次。

## 提取流程

### 0. 来源路由（开工第一步，决定走哪条路径）

按来源把论文分成两条路径，模型参与度差一个量级：

- **TeX/HTML 路径（arXiv 系论文的默认路径）**：论文有 TeX 源码（`<文件夹名>-src.tar.gz`）或 HTML（`<文件夹名>.html`）就走这条。公式本来就是 LaTeX、结构本来就分好章，转换以机械手段为主（pandoc 或脚本处理 HTML/tex），模型只做章节映射确认、六文件拼装和校对。**整理开工时发现 arXiv 系论文缺 TeX/HTML 的，先回 download 分册补下载，不要直接用 PDF 文本层硬啃公式。**
- **PDF-only 路径（CVF 老论文、IEEE 等无源码来源）**：用 `scripts/extract_pdf.py extract` 拿归栏拼装好的正文初稿，`outline` 拿章节候选，`refs` 拿参考文献切分初稿。公式从 PDF 文本层重建只发生在这条路径上，符号拿不准的照录原文并标注待核对，不猜。

### 1. 检查源文件与已有结果

记录标题、作者、年份、发表信息、总页数和 SHA-256，元信息缺失处注明"未载明"。

### 2. 章节映射与正文提取

先列出全部章节、附录、参考文献到输出文件的映射（含页码），再整本提取文本。PDF-only 路径下脚本输出已含页码标记（`<!-- pdf-page: N -->`）和跨页衔接；模型修正脚本无法处理的结构问题（图表题错位、跨栏块顺序等）。个别位置读不清时渲染该页确认；仍不确定就照录原文并标注待核对，不猜测。

### 3. 公式、表格与图注

- **有 TeX 源码时优先用源码**：文件夹内已有 `<文件夹名>-src.tar.gz` 就解压到 `tex/`，公式与表格优先从 `.tex` 转录——忠实度远高于 PDF 文本层；PDF 负责页码对照与图注定位。多文件源码包先辨认主 tex（通常含 `\documentclass`，或与论文同名）。
- 无源码时：公式转为 Markdown 可显示的 LaTeX；符号拿不准的照录原文并标注待核对，不猜。
- 表格完整转录：简单表格用 Markdown，复杂表格用 HTML；跨页表格合并为同一逻辑表，保留表头、数值、单位、脚注和加粗强调。
- 默认不提取图片：在原图对应位置保留图号与完整图注文字，并标注物理页码（如 "Figure 2（见源 PDF 第 4 页）"）。仅当用户明确要求时才保存图像到 `assets/`。

### 4. 参考文献与来源标记

- `references.md` 优先机械转录，模型不逐条重写：TeX 有 `.bib` 或 `thebibliography` 的直接转录；PDF-only 用 `extract_pdf.py refs` 的切分初稿整理条目内部换行。模型只抽查编号与正文引用标识的对应关系。
- 来源标记降到文件级：每个输出 MD 顶部一行 `<!-- source: 源文件名; pdf-pages: N-M -->`（写该文件内容覆盖的页码范围；source 始终写当前实际源文件名，无 PDF 锚点时省略 pdf-pages）。章节级页码映射记进篇级 `index.md`，不做逐块标记。文件与资源链接用相对路径。

## 完成标准与索引

篇级 `index.md` 记录：元信息（标题、作者、年份、发表信息、标识符）、源文件名与 SHA-256、总页数（无 PDF 时注明）、提取日期与所用工具、章节→输出文件映射（含页码）、文件导航、处理状态（已完成/部分完成）、待核对事项（指向具体文件位置与 PDF 页码）。

交付前检查：

- 四个主体 MD、references.md、index.md 齐全；原文没有的内容有注明。
- 所有原始章节都有归属，无遗漏、无重复；附录仅在实际提供时处理。
- 抽查通过（首页、章节交界、全部编号公式与表格对照文本无异常）。
- 待核对项均如实标注，未写成确定内容。

完成后把本篇的解析状态与待核对摘要写回库级 `index.md` 对应行，并向用户报告输出位置、处理状态与待核对内容。
