# 阅读与精读分析

按论文类型和用户的阅读目标分析原文，保留能返回原文的证据与进度。公共流程在本文件，具体分析问题按需加载，不默认同时读两个分支。

## 输入、身份与类型

- 开工先检查已有篇级 `index.md`、`report.md` 和源文件目录，明确实际产物与用户要求；索引状态可能过时，不能代替源文件和已读范围检查。
- 核对源文件首页或主 TeX 的标题、作者、版本及可用标识符，与目录和索引对应。没有页码或 DOI 时如实注明。发现错配时记录具体差异，暂不将这份内容归给目标论文；不自行删除或替换文件，可继续处理其他不受影响的论文。
- 优先读已提取的章节 Markdown 或 TeX/HTML 源；公式、图表或提取文本有歧义时返回源 PDF。没有整理产物也可直接读原文，不要求先重排或全文转换。只有标题/URL 且需要落库时衔接 `download.md`；仅分析时可读可访问的线上原文。
- 根据论文实际内容选择分支，不只依赖标题或目录名：

| 论文类型 | 分析手册 | 第一阶段正文模板 |
| --- | --- | --- |
| 方法、系统、基准或实证研究 | [analysis-method.md](analysis-method.md) | [report-method-template.md](../templates/report-method-template.md) |
| Survey / Review 等以梳理与综合已有研究为主的论文 | [analysis-survey.md](analysis-survey.md) | [report-survey-template.md](../templates/report-survey-template.md) |

混合论文按主要贡献选分支，再补充确有必要的另一类问题；不强套两个完整模板。综述没有原创模型或消融实验是正常情况。

## 阅读深度与完成情况

用户已明确要求精读或通读时，以覆盖正文为目标持续执行；分段落盘用于续读，不是提前交付定位阅读的理由。未指定深度时，可先定位结构，再按问题深入，并说明实际覆盖范围。

| 阅读方式 | 范围与用途 |
| --- | --- |
| 定位阅读 | 摘要、引言、章节结构与结论，识别范围、主张和深入位置 |
| 专题阅读 | 围绕具体问题读相关完整章节及必要的定义、图表、实验、限制条件 |
| 全文精读 | 分批覆盖正文，并按结论依赖进入附录与补充材料；记录未读或不可用部分 |

阅读方式与完成情况分开记录，例如“专题阅读（已完成）：导航终点的定义与实验”或“全文精读（部分完成）：已读 §1—3，§4—6 待读”。只有完成上述全文覆盖后才写“全文精读（已完成）”；不表示逐条复核参考文献或独立复现实验。已有“初步阅读”等状态可保留，但应补充实际范围，不能据旧标签推断全文已读。

## 分段阅读与上下文管理

1. 明确本轮问题，先定位目录、章节标题和主文件的 `\input` / `\include` 关系。搜索先用 `rg`，再读取命中处的完整论证及必要前后文；关键词未命中不构成主题缺失的证据。
2. 按自然论证单元读取，每批处理适量章节。长章节按定义、方法模块或实验问题再拆；保留变量定义、表头、表注及跨章节依赖。不要一次载入整个库、大型主文件或全部参考文献，也不为阅读强制转换现有 TeX。
3. 每批结束更新本篇 `report.md`：实际读过的源文件与章节、问题—解释—证据—边界、未解决依赖和下一阅读位置。报告概览保持简短，详细证据留在相应分析区域；不逐轮重复追加同一份全文摘要。
4. 续读时先读报告概览、覆盖记录和待办，再按需要返回原文；已有笔记是定位入口，不能取代重要判断和数字所依赖的原文核对。
5. 多篇比较按问题组织，每次只调入相关报告部分与原文；保留来源差异和相反证据。跨论文综合只在用户要求的范围内进行，不自动另建项目综述或扩展整个文献库。

## 证据与实质阅读

- 解释作者解决或组织了什么问题、依据什么假设、证据支持到哪里；不能只改写摘要或罗列目录。部分阅读中的推断明确标注，不用常识补齐未读实验或结论。
- 报告中的关键判断保留源文件及稳定位置：优先章节、图表或页码，必要时加当前行号或可检索短语。PDF 页码注明物理页码还是印刷页码；TeX 只有源码位置时不编造页码。
- 区分作者陈述、原文结果和阅读者推断。综述转述另一篇研究时，证据仍来自这篇综述，未读被引原论文就不能标为一手核查。
- 数字保留指标定义、数据划分、比较对象和实验条件；不以同名指标跨设置直接排名。图表的关键判断需要读表头、图注和必要正文，文本提取不足时核对原页。
- “未讨论某主题”等否定判断要说明已检查范围和近义表达；仅定位阅读或局部搜索时写“在已读范围内未发现”，不要泛化到全篇。

## 报告、恢复与交付

- 每篇一份 `report.md`。新报告从 [公共模板](../templates/report-template.md) 起稿；提取模式仍只填基本信息与提取报告，阅读模式维护自己的概览、覆盖记录、证据和类型正文。
- 读方法论文时插入方法正文模板，读综述时插入综述正文模板；仅加入适用分支。不适用、原文未交代、尚未读取分别注明，不能都写成无意义的空横线。
- 已有报告时保留提取区域、人工修订及既有分析，优先增量维护当前阅读区域；旧“精读报告”标题无需批量重命名。修正旧结论时写明新证据与修正原因，避免悄悄覆盖有冲突的人工判断。
- 源文件或版本发生变化时，标记受影响的覆盖记录和论点待复核，不直接沿用旧版本的完成状态或位置标记。
- 将阅读方式、完成情况及报告链接简要写回已有篇级/库级索引；具体覆盖与证据以报告为准，避免多处维护长笔记。
- 第一阶段是原文理解与批判性分析；全流水线也只执行第一阶段。第二阶段的额外问题与学术拓展由用户主动触发，完成后追加到同一报告，不预生成泛泛的延伸问题。
- 对话交付实际结论、报告位置、阅读范围和待核对项。报告可用完整 Markdown；对话不使用标题语法或水平分割线，必要时用列表与加粗组织，不使用斜体。

## 表达约定

- 用连贯自然的中文解释，技术细节服务于理解，不夸大作者贡献。
- 数学变量、公式与学术符号用 `$...$` 或 `$$...$$`；模型规模统一以 B 为单位，例如 3B、0.6B。
