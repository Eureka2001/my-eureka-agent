# 学术论文转 Markdown

将论文整理为后续综述写作、方法比较和文献检索可直接读取的资料。保留原文语言和完整论述；不以摘要、翻译或阅读笔记替代原文。

## 输入与执行范围

- 接受指定 PDF、PDF 清单或目录。未指定输入位置时，依次检查工作区的 `课题组相关论文/` 与 `参考/`；没有论文时，报告缺少的输入，不以其他 PDF 替代。
- 解析产物与源 PDF 同库存放：每篇论文一个文件夹，源 PDF 与全部解析产物并列在该文件夹内，不另设集中输出目录。课题组论文统一放在工作区根目录的 `课题组相关论文/` 下；其他论文以用户指定位置为准，沿用同样结构。
- 论文文件夹命名沿用源 PDF 文件名或用户指定名；需要新建命名时用 `<会议><年份>_<论文短名>_<作者缩写>`。文件夹内源 PDF 与文件夹同名。
- 每完成一篇，更新所属库索引（如 `课题组相关论文/index.md`）的清单与解析状态；用户指定位置没有索引时不强求新建。
- 保留源 PDF；只处理授权范围内的论文和输出。本机 Windows，Python 统一走 `uv run` / `uv add` / `uvx`，不寻找、安装系统 Python。

## 效率约束（防过度打磨）

- 源 PDF 均有可用文本层，以 pymupdf 文本提取为主，不做 OCR，不做全文渲染比对。仅个别扫描版 PDF 例外，此时才用 OCR 加页面检查。
- 提取用少量脚本批量完成：整本提取文本块 → 归栏拼装 → 写输出文件。避免逐页多次往返调用工具。
- 渲染页面只用于确认个别读不清的位置，不是常规步骤。整篇逐页渲染目检、词级/句级覆盖率校验、多分辨率放大取证均不需要。
- 核对以抽查为主：检查首页、各章节交界处，以及全部编号公式与表格——直接对照已提取的文本即可，无需截图。
- 状态只分两档：**已完成**（抽查无问题）、**部分完成**（仍有待核对标注）。不使用「已核对完成」一类暗示全量校验的说法。

## 每篇论文的输出

在论文文件夹内创建以下文件。保留原论文的章节名称、编号和层级；文件分类不代替原始章节结构。

| 文件或目录 | 内容 |
| --- | --- |
| `intro-related-work.md` | 完整 Introduction 和 Related Work；相关工作在引言内部时保留其原位置。 |
| `method.md` | 完整方法，以及服务于方法的问题定义、Background、Preliminaries、模型、算法和训练目标。 |
| `experiments.md` | 完整实验，包括数据集、设置、指标、主结果、消融、定量与定性分析。 |
| `abstract-conclusion.md` | 完整 Abstract 和 Conclusion；Discussion、Limitations 等独立章节保留原名称后归入此文件。 |
| `references.md` | 完整参考文献，保留原编号或作者年份标识，以及原文提供的 DOI、URL 等信息。 |
| `index.md` | 论文元信息、源 PDF 链接、文件导航、章节页码映射、处理状态和待核对事项。 |
| `appendices/` | 按原始附录结构或主题拆分的 Markdown；内容很少时可合为一个文件。仅有附录时创建。 |
| `assets/` | 默认不创建、不提取图片；仅当用户明确要求提取图片时创建。 |

将其余实质内容按用途归入上述文件，并在 `index.md` 记录归属。原文确实没有某类内容时，仍保留四个主体 MD，并注明“原文无独立对应章节”或其实际归属，不补造内容。正文中的嵌入式相关工作只在原位置保留一次。

## 提取流程

### 1. 检查源文件与已有结果

记录标题、作者、年份、发表信息、总页数和 SHA-256，元信息缺失处注明“未载明”。已有输出且源文件未变则跳过或续做；部分完成时从已记录位置继续，保留人工修订，不静默覆盖。

### 2. 章节映射与正文提取

先列出全部章节、附录、参考文献到输出文件的映射（含页码），再整本提取文本：按实际阅读顺序归栏拼装双栏正文，衔接跨页段落，移除页眉页脚与装饰页码，修复断词与编码问题。保留段落、列表、脚注、算法及其编号。个别位置读不清时渲染该页确认；仍不确定就照录原文并标注待核对，不猜测。

### 3. 公式、表格与图注

- 公式转为 Markdown 可显示的 LaTeX；符号拿不准的照录原文并标注待核对，不猜。
- 表格完整转录：简单表格用 Markdown，复杂表格用 HTML；跨页表格合并为同一逻辑表，保留表头、数值、单位、脚注和加粗强调。
- 默认不提取图片：在原图对应位置保留图号与完整图注文字，并标注物理页码（如 "Figure 2（见源 PDF 第 4 页）"）。仅当用户明确要求时才保存图像到 `assets/`。

### 4. 来源与引用

每个章节或跨页内容块加来源标记，物理页码从 1 起：`<!-- source: 源文件名.pdf; pdf-pages: N(-M) -->`；source 始终写源 PDF 当前实际文件名。`references.md` 完整逐条转录，与正文引用标识对应，不改写引用体系。文件与资源链接用相对路径。

## 完成标准与索引

`index.md` 记录：元信息（标题、作者、年份、发表信息、标识符）、源 PDF 文件名与 SHA-256、总页数、提取日期与所用工具、章节→输出文件映射（含页码）、文件导航、处理状态（已完成/部分完成）、待核对事项（指向具体文件位置与 PDF 页码）。

交付前检查：

- 四个主体 MD、references.md、index.md 齐全；原文没有的内容有注明。
- 所有原始章节都有归属，无遗漏、无重复；附录仅在实际提供时处理。
- 抽查通过（首页、章节交界、全部编号公式与表格对照文本无异常）。
- 待核对项均如实标注，未写成确定内容。

完成后向用户报告输出位置、处理状态与待核对内容。
